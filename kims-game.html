A memory game

Kim's Game

Study the tray of objects before the time runs out. When it's hidden, see how much you can remember.

Set up a game

How to play
  1. A tray of objects appears. Memorise as many as you can before the timer runs out.
  2. The tray is covered for a moment.
  3. What's missing? The tray comes back with some objects removed. Pick the missing ones from the choices below it.
  4. Recall the tray: You see a larger mix of objects. Pick every one that was on the tray.
  5. Each correct pick earns a point and each wrong pick loses one. A round never scores below zero.

Kim's game gets its name from Rudyard Kipling's novel Kim (1901), in which the young hero is trained to observe this way. Scouts and guides still play it today.
